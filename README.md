# Power BI Portfolio

Welcome to my Power BI portfolio.

This repository contains a collection of Power BI projects developed for **learning, practice, and skill development in data analysis and business intelligence**.

The projects demonstrate my ability to work with data from different business domains, transform and prepare data, build data models, create DAX measures, develop interactive dashboards, and communicate findings through business insights.

## Skills Demonstrated

- Data Cleaning & Transformation using Power Query
- Data Analysis
- Data Modeling
- Star Schema
- DAX Measures
- Time Intelligence
- Data Visualization
- Interactive Dashboards
- Business Insights
- Business Intelligence

## Projects

### Sales Dashboard

Retail sales analysis using the **Sample Superstore Dataset**.

Focus areas:
- Sales and profit performance
- Product categories
- Regional analysis
- Customer orders
- Business performance insights

### HR Dashboard

Employee workforce and attrition analysis using the **IBM HR Analytics Employee Attrition & Performance Dataset**.

Focus areas:
- Employee demographics
- Attrition analysis
- Department and job role analysis
- Income analysis
- Workforce distribution

### Finance Dashboard

Financial performance analysis using the **Microsoft Financial Sample Dataset**.

Focus areas:
- Sales and profit analysis
- Country and product performance
- Customer segments
- Cost and discount analysis
- Year-over-Year growth
- Time Intelligence

### Brazilian E-commerce Dashboard

End-to-end e-commerce analysis using the **Brazilian E-Commerce Public Dataset by Olist**.

Focus areas:
- Sales performance
- Customer behavior
- Product categories
- Delivery performance
- Payment methods
- Customer reviews

## Purpose of This Portfolio

These projects were created as practical exercises to strengthen my skills in **Power BI and data analysis**.

Through these projects, I practiced working with different types of datasets and business scenarios while developing skills in:

- Preparing and cleaning real-world datasets
- Building appropriate data models
- Creating analytical DAX measures
- Applying Time Intelligence
- Designing interactive dashboards
- Identifying meaningful business insights
- Presenting analytical findings in a clear and understandable way

The projects represent my learning journey and continued development in **Data Analysis and Business Intelligence**.
