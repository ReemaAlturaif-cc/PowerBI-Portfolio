# Sales Dashboard | Power BI 

## Project Overview

This project analyzes retail sales performance using Power BI.

The dashboard provides insights into sales, profit, customer orders, product performance, categories, and regional sales to support business decision-making.

It was developed as a portfolio project to practice retail data analysis, data preparation, data modeling, DAX, and interactive dashboard development. 

---

## Business Understanding

The purpose of this project was to analyze retail sales performance and identify patterns in sales, profit, orders, products, categories, and regions.

The project was selected to practice working with retail sales data and to demonstrate how Power BI can be used to transform business data into meaningful insights.

One of the main challenges was preparing the data model and creating relationships between fact and dimension tables to support accurate sales and profit analysis.
 
---

## Dataset

**Superstore Dataset**

The dataset contains retail sales information covering orders, customers, products, categories, regions, sales, and profit.

The dataset was selected because it provides a practical retail business scenario for analyzing sales performance and practicing data modeling and business intelligence techniques.

## Data Preparation

The data preparation process included:

- Removed records with negative profit values.
- Created a Category Hierarchy.
- Created a Customer Hierarchy.
- Created a dedicated Date table.
- Created relationships between the fact and dimension tables.
- Prepared the data model for analysis.

--- 

## Data Model

The project uses a Star Schema consisting of:

- Fact Tables
- Dimension Tables
- Dedicated Date Table
- Relationships between fact and dimension tables
---

## Analytical Approach

The analysis followed these main steps:

1. **Data Preparation**
   - Reviewed and cleaned the retail sales dataset.
   - Removed records with negative profit values.
   - Created hierarchies and prepared the data for analysis.

2. **Data Modeling**
   - Built a Star Schema.
   - Created fact and dimension tables.
   - Created a dedicated Date table.
   - Established relationships between the tables.

3. **DAX Analysis**
   - Created measures to calculate total sales, total profit, profit margin, and total orders.

4. **Data Visualization**
   - Created interactive dashboards using KPIs, charts, filters, and time-based visualizations.
   - Analyzed sales performance across categories, regions, and products.

5. **Business Insights**
   - Compared sales performance across product categories and regions.
   - Identified high-performing categories and regions.
