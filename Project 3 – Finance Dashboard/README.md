# Finance Dashboard | Power BI

## Project Overview

This project analyzes financial performance using the Microsoft Financial Sample Dataset and Power BI.

The dashboard focuses on sales, profit, costs, product and country performance, customer segments, and year-over-year growth. It was developed as a portfolio project to practice financial data analysis, data modeling, DAX, and Time Intelligence in Power BI.

---

## Business Understanding

The purpose of this project was to evaluate financial performance and identify trends in sales, profitability, costs, and product and country performance.

The project was selected to practice financial data analysis using Power BI and to strengthen skills in DAX, Time Intelligence, and interactive dashboard development.

One of the main challenges was creating time-based calculations such as Year-to-Date sales, Previous Year Sales, and Year-over-Year Growth while ensuring that the Date table and filtering context were correctly configured.

---

## Dataset

**Microsoft Financial Sample Dataset**

The project uses the Microsoft Financial Sample Dataset, which contains financial information related to sales, profit, costs, products, countries, and customer segments.

The dataset was selected because it provides a practical business scenario for analyzing financial performance and applying Power BI data modeling, DAX, and Time Intelligence techniques.

**Source:** [Microsoft Learn – Financial Sample Dataset](https://learn.microsoft.com/power-bi/create-reports/sample-financial-download)

## Data Model

The project uses a structured data model with a dedicated Date table connected to the financial data.

The Date table was used to support time-based analysis and DAX Time Intelligence calculations such as YTD Sales, Previous Year Sales, and YoY Growth.

---

## Analytical Approach

The analysis followed these main steps:

1. **Data Preparation**
   - Reviewed the financial dataset.
   - Prepared the date information for analysis.

2. **Data Modeling**
   - Created a dedicated Date table.
   - Established relationships between the Date table and the financial data.

3. **DAX Analysis**
   - Created measures for sales, profit, gross sales, COGS, discounts, and profit margin.
   - Applied Time Intelligence calculations including YTD, Previous Year, YoY Growth, and Running Total.

4. **Data Visualization**
   - Created interactive dashboards to analyze sales and profitability.
   - Used KPIs, charts, slicers, and time-based visualizations.

5. **Business Insights**
   - Compared financial performance across countries, products, and customer segments.
   - Identified sales trends and year-over-year changes.
